# A.1 Página de enquadramento

Usada antes de qualquer pedido ao agente (Capítulos 1 e 12). Cabe em uma página.

**Modelo de página de enquadramento**

| Campo | O que registrar |
|---|---|
| Resultado esperado | Comportamento observável para quem recebe o serviço |
| Pessoas afetadas | Quem usa, decide, atende, opera ou recebe consequência |
| Regras preservadas | O que não pode mudar: contratos, políticas, comportamentos existentes |
| Fora do escopo | O que fica explicitamente para depois |
| Riscos principais | O que pode dar errado e para quem |
| Autonomia concedida | Nível da escala para cada etapa (investigar, implementar, executar) |
| Evidências exigidas | O que demonstrará que o trabalho terminou |
| Condições que invalidam | Situações que impedem a liberação, mesmo com o código pronto |
